# 后台管理系统前端

React 19 + Vite 7。生产构建由后台 Express 服务在 `127.0.0.1:8770` 提供；开发服务器默认位于 `127.0.0.1:5175`，API 代理至后台服务。登录令牌仅保存在当前标签页的 `sessionStorage`，页面不请求外部字体或分析服务。

请通过 `http://127.0.0.1:8770/` 访问后台。不要直接打开 `index.html` 的本地文件地址；它不是可独立运行的页面，直接打开时会跳转到本地后台服务。

```sh
pnpm install
pnpm dev
pnpm build
```

页面提供概览、用户、项目、生成任务和质量评价的只读列表与筛选；不承载原图、生成图、原文件名或草稿数据。
