# 无垠空间 · 平面图生成室内效果图原型

基于 PRD v0.1 的本机单用户网页工作台。源码、资源副本和运行结果均保存在本目录，原始项目资料保持不变。

## 启动

macOS 双击 **启动网站.command**。脚本会打开已运行的网站，或从 8766 开始选择一个空闲端口并启动服务。终端窗口需保持打开；按 Control+C 停止。

本机也可使用 Codex 自带 Python：

```sh
cd '/Users/gaojiazhe/Documents/workspace/project-002-平面转效果图/002-产品原型、前端代码/fronted'
'/Users/gaojiazhe/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3' server/app.py --port 8766
```

打开 <http://127.0.0.1:8766>。不要直接双击 public/index.html，也不要使用仅静态文件服务器，否则上传、保存与模型任务接口无法工作。

迁移到其他电脑时：使用 Python 3.10+，安装 requirements.txt；真实生图还依赖下述 imageStyle 服务及其运行环境。

## 已实现

- 样例：无垠住宅的平面图、设计说明及 13 张人工效果图副本。原 DWG 不解析、不改动。
- 上传 JPG/PNG/PDF；多页 PDF 可选页。文件上限 25 MB，PDF 最多 30 页。
- 真实模型识别房间、门窗及固定家具，提供推荐观察点；不确定与无尺寸信息需人工核对。
- 上传后即时显示平面图缩略图；房间选择、手动框选、拖动八个边角手柄调整范围，支持方向键微调。
- 结构与尺寸纠正、层高补充、观察点微调、东南西北及四个斜向的摄像机朝向选择、一次确认。
- 六种风格、文字意向与可选参考图，基于平面图进行真实生图。
- 局部矩形蒙版重绘、全图换风格、连续版本、历史返回、图片下载。
- 人工参考与 AI 结果明确分开，滑块对照、人工验收勾选。
- 本地持久化、异步任务查询、重复请求去重、刷新恢复。超时或进程中断标记结果未知，不自动重新扣费生成。
- 桌面及移动端布局、项目入口、参考图库与使用指南。

## 模型连接

复用本机已安装的 imageStyle 服务：

- 默认目录：`~/.codex/mcp-services/imageStyle-1.1.6`，可用环境变量 `IMAGE_STYLE_SERVICE` 覆盖。
- 生图调用该目录的 `.venv/bin/python` 与 `route_a_image.py`，使用该服务已有的图像模型配置。
- 结构识别使用同一服务的认证方式调用 `/chat/completions`，默认视觉模型 `gpt-5.6-luna`，可用 `VISION_MODEL` 覆盖。
- 密钥由原有本机配置读取，不复制到原型、不进入浏览器。配置检测不代表上游持续可用。
- 用户勾选发送确认后才调用模型。当前服务目的地为 `mckj.hk.cn`。平面图、参考图或编辑基图将发送至此服务；未提交的资料仅保存在本机。
- 生图单任务等待上限 600 秒，识别为 120 秒；未提供实际金额的接口不显示虚构成本。

## 文件与资料管理

- `public/`：网页源码和必要素材副本，无外部 CDN 依赖。
- `server/app.py`：本地服务，绑定 127.0.0.1。
- `outputs/uploads/`：上传图片、PDF 渲染页，图片去除 EXIF。
- `outputs/generated/`：真实生成与编辑结果。
- `outputs/jobs/`：任务状态、提交参数、时间、识别使用量（接口返回时）。
- `outputs/workspace.json`：当前工作区和版本元数据；本原型仅维护一个当前工作区。
- `work/`：生成用图纸副本、裁切图、蒙版与测试临时材料。

清理资料时，先停止服务，再按需删除 outputs/ 中的对应资料及 workspace.json。已发给模型服务的资料应按该服务的数据处理规则管理。本地服务未实现多人账号和云端授权，不适合直接暴露到公网。

## 已知能力边界

- 图像模型的结构保持由提示词和图纸参考引导，尚无几何约束引擎，不能保证墙体、门窗或比例绝对准确；必须逐图人工验收。
- 局部编辑传入与基图同尺寸的透明蒙版，并在本地合成时严格保留矩形选区外像素；必要阴影必须包含在选区内。选区内的结构和物体体量仍需核对。
- 全图换风格没有像素锁定，可能发生布局漂移，不能作为已通过结构验收的结果。
- 推荐观察点并未进行三维碰撞检查，设计师需确认未位于墙体或家具内。原图无尺寸时不生成精度承诺。
- 替换平面图会开始新的当前工作区；旧生成文件仍留在 outputs/，但不再列在新图纸的版本面板中。
- 完整 CAD 解析、多视角一致性、施工图、商业计费和多人协作均未实现。
