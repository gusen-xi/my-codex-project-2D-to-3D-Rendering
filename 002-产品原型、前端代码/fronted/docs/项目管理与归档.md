# 空白工作台、我的项目与样例

## 交互规则

- 每次输入密码登录或注册后，进入未上传图纸的空白工作台，不自动恢复上一项目、不预载无垠图纸，也不创建空数据库项目。
- 同一标签页刷新时，恢复正在编辑的项目；退出再输入密码登录，则重新回到空白状态。历史数据仍在“我的项目”，不会因为清空界面而删除。
- “我的项目”提供右上角“新建项目”、空白创建卡和侧栏快捷入口。弹窗只要求项目名称，支持取消、空白校验、提交等待和失败提示；创建后进入空白项目。
- 也可从空白工作台直接上传，系统按文件名创建项目。上传后继续原有选房间、核对、选风格、生图和局部重绘流程。
- 草稿自动保存到当前项目。个人卡片显示项目名称、草稿/生成中/已生成状态、版本数量、最新生成结果和更新时间；点击“继续设计”或“查看成果与继续设计”恢复该项目。
- 生图或编辑成功后，服务端在保存图片、任务状态的同时，将成果追加到该项目的版本表。重新登录后仍能从项目中查看；不会靠前端临时数组冒充归档。
- 替换同一项目的平面图不删除已生成版本。开启独立方案时应点击“新建项目”，让图纸、任务与版本分别归档。
- 当前任务运行时允许前往“我的项目”查看或打开另一个项目，服务端继续处理原任务；为避免误操作，当前任务运行时不从其工作台直接新建。上传过程中禁止切换项目或退出，避免图纸归属错位。

## 样例与旧数据

“无垠住宅项目”单独展示在“示例项目”，标记“只读展示”“不计入我的设计”。点击打开样例弹窗，展示原始平面图、人工效果图和既有ComfyUI真实AI生成/局部编辑结果；不发起新的模型请求。提供“新建自己的项目”按钮，创建自己的空白项目，而非编辑内置样例。

旧数据库中 `is_sample=1` 的样例项目不计入个人项目数量。其已有生成版本仍保存在原表，并在只读样例弹窗的“已有验证记录”中展示；不删除、不覆盖。`is_sample=0` 的既有个人项目继续出现在个人列表。

人工参考图仅作为对照，不标为AI成果。现有技术验证页面和证据文件保留。

## API与数据归属

业务接口沿用Node网关转发至Python，使用当前标签页的Authorization认证。复用已有MySQL `projects` 及关联表，本次无需新增建表脚本。

| 接口 | 作用 |
|---|---|
| `GET /api/projects` | 当前账号项目列表：id、name、isSample、versions、status、cover、updated |
| `POST /api/projects` | JSON `{name}`，创建非样例项目；201返回id/name；名称1–128字符 |
| `GET /api/workspace` | 未指定项目时返回null，不创建或恢复默认项目 |
| `GET /api/workspace?projectId=ID` | 显式打开本人项目；无权访问返回404 |
| `POST /api/workspace` | 保存草稿，JSON必须含有效projectId；支持未上传的空草稿 |
| `POST /api/upload` | 上传并登记到projectId对应项目 |
| `POST /api/analyze`、`POST /api/generate` | 请求必须含projectId，按项目校验素材、房间及父版本归属 |

写入前检查项目所有权；请求幂等编号在项目内唯一，即使两个项目使用相同编号，也不会串用任务。私有图片继续校验账号所有权，引用为另一个项目的输入时还需验证所属项目。

## 验证

19项Python集成/工作流测试通过，包含多项目创建、空白入口不自动建档、项目草稿相互独立、跨账号拒绝、跨项目素材拒绝、同编号跨项目任务不串用、生成/编辑成功后列表版本数与封面恢复。模型使用模拟输出，不产生新费用。

Node认证6项测试、八向视角/选框测试、空白工作台状态测试、语法检查和Vite生产构建通过。

浏览器验证：密码登录为空白 → 查看只读样例 → 命名新建 → 上传 → 列表出现草稿 → 退出再登录为空白 → 打开项目恢复图纸。测试使用既有测试账号，新增的浏览器验证草稿和上传副本已清理，不删除原有项目。本轮未重新调用付费生成模型。
