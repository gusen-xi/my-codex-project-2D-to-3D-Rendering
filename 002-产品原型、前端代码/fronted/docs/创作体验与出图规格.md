# 创作体验与出图规格

更新：2026-11-17

## 交互变更

1. 项目参考图库采用「项目封面 → 房间分组 → 参考图片」层级。当前只有真实的无垠图库，不预置虚构项目。`collections` 为项目集合，图片可用 `collectionId` 关联；现有图片默认属于 `wuyin`。
2. 核对空间提供长、宽两个净尺寸输入框，单位米，范围 0.1–100，支持两位小数；未知留空，不从图片框选比例推算。尺寸备注单独保留。变更后取消原空间确认。
3. 六种风格用本地室内照片／项目效果图展示，补充材质、配色提示。图片只表达风格方向，并非生成结果，也不承诺逐件复刻。来源见 `public/assets/styles/sources.html`；第三方项目图的商业公开发布需另行确认授权。
4. 局部选区支持八个边角缩放、拖动移动、方向键微调、Shift 加速、清除和重新框选；不会越过图像边界。切换编辑对象清除旧选区。
5. 头像点击后打开文件选择器，支持 JPG、PNG、WebP，最大 5 MB、2500 万像素。服务端纠正方向、裁为 256×256 并重新编码为 PNG。文件保存在 `outputs/avatars/<账号ID>.png`，读取按当前登录账号鉴权，刷新后恢复。不会覆盖原始图片。
6. 有生成版本时，局部修改面板上方提供「按当前方案再生成」及「开始新创作」。前者保留方案返回出图设置；后者先保存旧项目，回到无上传内容的工作台，下次上传自动建立新项目。
7. 删除截图标记的我的项目页右上新建按钮、自动保存说明、示例标题旁只读标签、过程介绍文字。仍保留新建卡片与侧栏入口，以及必要的样例性质说明。

## 生成规格与实际数据

| 参数 | 首版可选值 |
| --- | --- |
| 画幅／请求像素 | 横幅 3:2／1536×1024；方形 1:1／1024×1024；竖幅 2:3／1024×1536 |
| 质量 | low 草稿；medium 标准；high 精细 |
| 数量／导出 | 每次 1 张；PNG |
| 默认 | 横幅、标准质量 |
| 局部修改／换风格 | 模型请求按原图比例匹配支持的画幅，最终保留原图像素尺寸 |

设置经过服务端白名单校验，实际传入已安装 `route_a_image.py` 的 `--size`、`--quality` 参数；该 CLI 的质量枚举为 low/medium/high。长宽以米明确写入生成提示词，未知尺寸不伪造。

长宽、规格随 `projects.workspace_draft` 和 `model_tasks.request_snapshot` JSON 保存；实际返回像素保存在素材记录及任务结果，版本列表展示实际尺寸。无需清库或修改现有表结构。模型是否完全遵守指定尺寸和结构仍须用真实生成检验，不把参数选项等同于能力保证，不承诺费用、时间和4K。

局部修改保留未选区域的像素；换整体风格保持原图尺寸。跨账号无法读取头像、图纸或生成结果。

## 调研来源与取舍

- [Midjourney Editor](https://docs.midjourney.com/hc/en-us/articles/32764383466893-Editor)：借鉴编辑后可继续调整的选区体验；本版用项目已有矩形选区，不增加画笔等额外工具。
- [Adobe Firefly 画幅设置](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/set-aspect-ratio-of-images.html)：比例与像素尺寸同屏表达，按当前连接模型支持范围提供预设。
- [Adobe Firefly 生成图像](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/generate-images-from-text-descriptions.html)：借鉴视觉风格选择、保留设置再生成与开启新创作的区分。

## 验证与边界

- Python/MySQL：22 项测试，含尺寸合法性与草稿恢复、参数传递、头像持久化与账号隔离、局部合成与历史版本等；数据库测试使用独立临时库。
- JavaScript 后端：6 项账号／会话测试。
- 前端几何断言：八向、八个缩放手柄、最小尺寸和选区移动边界；空白工作台隔离测试。
- 语法检查和 Vite 构建通过。
- 浏览器真实操作：图库分层、上传缩略图、长宽填写与恢复、6 张风格图片加载、规格选择、局部框选后缩放移动、头像本地上传、项目页冗余删除、沿用方案和新创作。
- 本轮未消耗收费模型请求。服务端模型调用测试使用替身；浏览器完成态使用明确标注的临时样例。临时项目、任务、图片、测试头像已清理，不作为实际生图结果保留。
