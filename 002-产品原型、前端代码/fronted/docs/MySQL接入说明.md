# MySQL 接入与本地运行

网站现已使用本机 MySQL 8.4 的 `wuyin` 数据库保存账号、项目草稿、素材元信息、房间、模型任务、结果版本和人工评价。图片/PDF继续放在 `outputs/`；人工样例仍在 `public/assets/`。没有修改图片生成服务的凭据或接口。

## 启动与连接

1. 启动 Docker Desktop，确认 `wuyin-mysql` 容器处于运行状态。
2. 双击原型根目录 `启动网站.command`，访问 http://127.0.0.1:8766 。
3. 使用原有网站账号和密码登录。数据库用户名 `wuyin` 是服务端连接账号，与网站用户名不是同一概念。

新增 Python 依赖为 `PyMySQL[rsa]`，已在本机网站运行时和 ComfyUI 虚拟环境安装。其他电脑需使用 Python 3.10+ 执行 `python3 -m pip install -r requirements.txt`。

默认连接 `127.0.0.1:3306`，读取项目根目录 `work/mysql/.env` 中的 `MYSQL_USER/MYSQL_PASSWORD/MYSQL_DATABASE`。可用环境变量 `DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME` 覆盖。配置仅由后端读取，不返回前端，也不进入 Git。

不要使用容器中旧的 `MYSQL_PASSWORD` 环境变量验证新密码：修改数据库账户密码后，已有容器的初始化环境值不会自动改变。网站读取的是本机已经同步更新的 `.env`。

## 数据读写

| 网站功能 | 写入位置 |
|---|---|
| 注册、登录密码校验 | `users`（盐、PBKDF2哈希及迭代次数） |
| 登录会话、注销及过期时间 | `auth_sessions`（只保存随机令牌摘要） |
| 工作区刷新恢复、当前风格/步骤等草稿 | `projects.workspace_draft` |
| 上传图片、PDF原件及拆页、人工参考图、生成图片元信息 | `assets` |
| 房间选框、结构核对、尺寸及摄像机 | `rooms` |
| 模型请求、状态、结果、失败诊断、上游用量 | `model_tasks` |
| 成功结果、父版本、版本号 | `render_versions` |
| 三项人工核对勾选 | `version_reviews` |

任务输入快照在提交时固定；成功结果由服务端入库，而非依赖前端伪造版本列表。任务状态从数据库查询，重启后可恢复，未完成且没有完成证据的任务标为 `unknown`，不会自动重发付费请求。模型结果首先写入本地恢复日志；如果随后数据库写入失败，重启服务可用完成日志补录图片版本。

当前支持一个账号多个项目，上传、房间、任务与版本按projectId归属。每次密码登录为空白工作台，不覆盖已有草稿；从“我的项目”明确打开后恢复。生成结果自动归入对应项目。旧样例项目只读展示，原有版本保留；替换同一项目图纸不删除历史版本。详见 [项目管理与归档](项目管理与归档.md)。

## 登录与访问范围

浏览器使用当前标签页的sessionStorage保存随机会话令牌，经Authorization请求头由后端验证；不信任 `localStorage` 中的用户名，也不接受旧登录Cookie。复制地址到新标签页需重新登录，刷新原标签页保留登录；退出只撤销当前标签页会话。登录/注册由Node.js后端提供，会话摘要写入新增的 `auth_sessions` 表，最长七天，服务重启后仍有效；Node和Python共同验证该表。旧内存会话在本次切换后需重新登录一次。详见 [后端说明](../../backend/README.md)。

工作区按账号归属读取；上传和生成图片的请求须校验素材所属项目，不能用另一个账号的图片路径或任务ID读取数据。样例素材、静态工作流和配套验证证据仍公开在本机原型中。此部署仍只监听本机，不是公网部署方案。

独立运行的 ComfyUI 节点没有网站登录上下文，继续保留原有本地任务日志，不自动归入某个网站账号；网站提交的任务以 MySQL 为主。技术验证页面仍读取静态工作流与历史证据。
