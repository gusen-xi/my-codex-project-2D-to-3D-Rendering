# 平面转效果图

## 项目目标

面向住宅室内设计师、软装设计师和小型设计工作室，将户型平面图转为单房间风格意向图，并支持局部重绘，用于初次客户沟通。

## 核心材料

- [产品 PRD v0.1](001-产品prd/平面图生成室内效果图_PRD_v0.1.md)：需求草案、首版范围、产品规则、验收标准与未决问题。按用户指定目录保存。

- [网站原型与启动说明](002-产品原型、前端代码/fronted/README.md)：网页源码、真实项目素材副本、模型连接和本地运行说明。

## 当前状态与验证

- 已完成需求采访，已保存 Markdown PRD v0.1。
- 已实现网页原型，并以无垠项目开展真实模型验证；包含上传、识别核对、风格选择、生图、局部编辑、版本历史和人工图对照。

## ComfyUI 技术验证入口

网站左侧新增“技术验证 → ComfyUI 工作流”，展示实际 JSON 的完整节点和连接，支持查看参数与下载导入。配套节点源码、样例及运行说明位于 `002-产品原型、前端代码/fronted/comfyui/`，验证状态和执行证据位于 `002-产品原型、前端代码/fronted/public/workflows/`。工作流接入现有图像 API，并保留人工确认和结构精度验收边界。

本次已使用真实 ComfyUI 引擎完成识别、生图及局部编辑，两张 PNG 与原始执行历史均已保留；选区外像素一致性检查通过。首次生图约 335 秒、编辑约 142 秒，几何精度仍需人工验收。

网站代码已整理至 `002-产品原型、前端代码/fronted/`；浏览器端、静态资源、本地服务、脚本、测试与文档分别归档，启动入口见该目录 README。
