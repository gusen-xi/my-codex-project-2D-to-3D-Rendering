# 平面转效果图

## 项目目标

面向住宅室内设计师、软装设计师和小型设计工作室，将户型平面图转为单房间风格意向图，并支持局部重绘，用于初次客户沟通。

- [产品 PRD v0.1](001-产品prd/平面图生成室内效果图_PRD_v0.1.md)：需求草案、首版范围、产品规则、验收标准与未决问题。按用户指定目录保存。

- [后台管理系统功能需求 v0.1](001-产品prd/后台管理系统功能需求_v0.1.md)：只读查看用户、项目、生成任务和质量评价的管理后台需求；明确禁止修改数据库与表结构。

- [网站原型与启动说明](002-产品原型、前端代码/fronted/README.md)：网页源码、真实项目素材副本、模型连接和本地运行说明。

- [数据库表结构与执行说明](003-数据库脚本/README.md)：MySQL 8.4 七张业务表和一张认证会话表、建表 SQL、前端字段映射与临时库验证脚本；网站已接入 MySQL，旧账号和设计记录已迁移，详见原型的 MySQL 接入说明。

- [项目管理与归档交互](002-产品原型、前端代码/fronted/docs/项目管理与归档.md)：登录后空白工作台、多项目创建、成果自动归档及只读样例。

## 生图质量评价

结果页“质量评价”按钮打开版本关联的评价弹窗，收集总体体验、结构/布局/客户沟通/局部编辑保持情况、多选问题类型和自由文本意见。评价沿用 `version_reviews` 现有字段保存，意见以 JSON 写入 `notes`，不新增或修改数据库表结构。管理后台的“质量评价”列表会展示总体体验、问题标签和补充意见；旧版纯文本备注也会按补充意见兼容展示。
